# 範例 00：Hello, Rust!

對應：第一章「安裝工具並建立第一個專案」

## 目標

確認 Cargo 專案結構，執行第一個 Rust 程式。

## 前提

已安裝 Rust 與 Cargo。此範例目前以 Rust 2024 Edition 撰寫；Repo 維護者尚未在建置環境實際執行，請將它視為初始範例，待工具鏈驗證後更新狀態。

## 執行

在本資料夾執行：

```bash
cargo run
```

預期輸出：

```text
Hello, Rust!
```

## 自我練習

1. 將輸出文字改為自己的問候語，再執行一次。
2. 說明 `src/main.rs` 與 `Cargo.toml` 各自負責什麼。
3. 故意刪除一個括號，執行程式並記錄編譯器指出的位置；修復後再次執行。

執行結果與錯誤訊息會依工具鏈版本略有差異，以成功編譯及輸出你修改後的文字為完成判準。
