# 範例索引

本資料夾存放可獨立執行的 Cargo 專案。每個範例目錄都應附 README，說明對應章節、工具鏈需求、執行命令、預期結果、練習及驗證狀態。

範例：

- `00-hello-rust/`：第一章起始程式；尚待在安裝 Rust 的環境實際執行驗證。
- `12-rust-log-summary/`：第九至第十二章最終專案檢查點，附完整 source、sample、單元與 CLI 整合測試；本次工作環境沒有 `cargo`／`rustc`，尚未在此副本重新執行測試。

`LICENSE-CODE` 的 MIT 授權僅適用於 `examples/**/*.rs`，不涵蓋本索引、各範例 README 或其他文件。
