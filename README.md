# Rust 實戰入門｜讀者配套資源

本 Repo 提供《Rust 實戰入門：從所有權到命令列工具》的可下載範例、練習與資料檔。它是書籍的補充資源，不包含書稿。

## 下載

- ZIP 下載：[下載 main 分支壓縮檔](https://github.com/t945935/rust-practical-beginner-resources/archive/refs/heads/main.zip)
- Git 複製：

```bash
git clone https://github.com/t945935/rust-practical-beginner-resources.git
```

解壓或複製後，從 Repo 根目錄依各資料夾 README 指示操作。

## 目前狀態

目前提供第一個起始範例：`examples/00-hello-rust/`。其餘章節的練習、合成資料與解答將依書稿進度逐步加入。此範例尚未在本次建置環境執行：目前環境沒有安裝 Rust；讀者可先依 Rust 官方文件安裝 Rust/Cargo，再執行範例。

建議工具鏈基準為 Rust 1.97.0 或更新 stable、Rust 2024 Edition；出版版與各資源版本須以書稿凍結時重新確認的版本為準。

## 資源索引

- `examples/00-hello-rust/`：Cargo Hello World 起始專案。
- `exercises/`：逐章練習（建置中）。
- `data/`：合成文字紀錄測試資料（建置中）。
